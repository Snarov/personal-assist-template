# Рабочая рутина

Отдельный дневной лог обычной работы вне фокус-задач Personal OS. Он нужен, чтобы сопоставлять нагрузку от двух рабочих проектов со временем, которое остаётся на основные цели, и с тем, насколько рутина отвлекла.

| Путь | Что это |
| --- | --- |
| `work-routine.spec.json` | Шкалы и JSON Schema дневной записи |
| `entries/YYYY-MM-DD.json` | Один день по часовому поясу Europe/Moscow |

Вечерний ритуал спрашивает одним блоком:

1. что было сделано по рабочим проектам;
2. сколько минут или часов ушло на каждую часть;
3. насколько рутина отвлекла от фокус-задач: 1–3.

Если рутины не было, достаточно ответа «рутины не было». Если было несколько дел, но владелец назвал только общее время, они остаются одной записью: агент не придумывает разбивку.

Пример закрытого дня:

```json
{
  "spec": "work-routine",
  "specVersion": "1.1.0",
  "date": "2026-09-18",
  "weekday": "пт",
  "status": "complete",
  "activities": [
    {
      "project": "Рабочий проект",
      "description": "Разобрал обращения и обновил конфигурацию",
      "minutes": 150
    }
  ],
  "totalMinutes": 150,
  "distraction": 2,
  "source": "voice"
}
```

Правила чтения и записи — в `.cursor/skills/routine-log/SKILL.md`.
